# ✨ Dlaczego Devek?

Devek powstał z myślą o programistach, którzy chcą korzystać z nowoczesnych narzędzi bez zbędnej konfiguracji.

Projekt skupia się na:

* ⚡ wysokiej wydajności
* 🧩 prostym interfejsie
* 🔓 otwartym kodzie źródłowym
* 🌍 wieloplatformowości
* 🚀 szybkim rozpoczęciu pracy
